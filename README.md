# Practical 6: Create Operation (Unit 5 Prac 1)

## Aim
Develop a Product Management React application that allows the user to enter product details through a form and add a new product to the application.

## GitHub Repository
`https://github.com/mayuri2907/u5-prac1.git`

## Concepts Implemented
- **Create Operation**: Adding a new item to the application state using the array spread operator (`[newProduct, ...products]`).
- **Controlled Input Form**: Manages Product Name, Category, Price, and Stock fields.
- **Dynamic List Rendering**: Renders the updated product list in an HTML table using the `.map()` method.
- **Inventory Metrics**: Computes dynamic total item count and inventory valuation.

## How to Run Locally
```bash
npm install
npm run dev
```
